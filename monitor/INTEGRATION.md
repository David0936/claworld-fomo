# Fomo 自动化 → 飞书 / Telegram 推送

此文件是原自动化的补充接口，原有筛选、生命周期及三套策略规则继续有效。用户已授权将合格信号和提醒发送到本机配置的飞书和 Telegram 接收方。无需再确认发送。密钥只由推送服务读取，不要读取或输出 ~/Library/Application Support/FomoMonitor/data/config.json。

## 每轮状态

在项目根目录使用 `/usr/bin/python3 monitor/bridge.py scan running --detail '开始检查 GMGN 热搜和 Windvane'` 写入开始状态。

结束时同命令使用 complete、partial 或 blocked，--detail 写具体检查结果，--chains 用逗号列出本轮实际核验的链。未检查完全部目标链必须 partial，不可写 complete。登录失效、浏览器不可用、查询配额、抓取错误必须显式记录，禁止用“无新命中”掩盖。

## 即时推送事件

发现每个新命中时先建立原有 Markdown 基线记录，然后立即将一个 JSON 对象写入本地临时文件，通过 `bridge.py event 文件绝对路径` 入队；不要等全链扫描结束再通知。后台每2秒检查队列并发送到已启用的飞书和 Telegram 通道。重复 id 自动忽略；网络失败自动重试。请勿直接调用飞书，勿读取密钥。

JSON 公共字段：

- id：稳定事件标识。新命中使用 `hit:链:完整CA`；倍数提醒使用 `milestone:链:完整CA:2x` 等。回撤、策略、风险通知用稳定触发编号；同一事件重试必须复用 id。
- kind：hit / milestone / risk / stopped / strategy / outage / recovery。
- observed_at：真实观测时间，包含时区。
- text：完整中文提醒。写明链、名称、完整CA、观测时间、价格及是否估算、市值、年龄、Fomo占比及人数、流动性、Top10、24h涨跌/成交量、停止线、可用的直接来源链接、相关策略状态。缺失指标明确写未核验。

hit 额外必填：`source: "windvane"`，`verified: true`，`chain`，`ca`，`age_days`（数值），`market_cap`（美元数值），`fomo_ratio`（百分数，例如17.1）。服务器再次检查 1–7 天、200000–500000 美元和至少15%。

Windvane 若显示范围，只用可信下界筛选。≥14.5% 或14.5%–15.6%不能确认低于15%，也不能确认命中。未知值不可替代为0，不可累计连续两次低于阈值。Top10等不能冒充 Fomo 占比。WOOD历史记录有估算值且已触发过历史倍数，不能倒填新事件或模拟成交。

频率：新标的筛选随每轮自动化执行；已有代币生命周期和模拟模型仍按原定每两小时采样，手动即时核验可以更新行情但不得把短时间重复查询冒充两次定时确认。记录真实采样时间，行情无变化不发消息。扫描被同一原因阻塞，只在首次故障和恢复各通知一次。

无法写入事件队列时必须在原任务报告，不得声称已推送。入队不等于已发送；`bridge.py status` 的事件 sent 表示该事件全部目标通道均已接受。

推送目的地由本机服务配置自动选择，采样任务不要在事件中填写 channels；所有启用通道会独立投递并重试。新配置通道不重放已发送历史。


## 100U 模拟观察表

参见 [PORTFOLIO.md](PORTFOLIO.md)。每个标的从首次核验合格的观测价独立投入100U，回放三套策略（模型3含100U/110U两分支），逐笔扣买卖成本。按各标的所在链和每笔交易金额计算官方平台费；额外费用未核验时不冒充实测总成本。已付费用与剩余仓位预估卖出费分开展示。无后续报价时显示待采样，不计入当前收益汇总。历史50U日志保留，页面为独立100U回放账本。

每轮扫描必须按 PORTFOLIO.md 的清单状态协议，为当前主清单每个标的写入一次带 `watch_round` 的资格判断。连续3个有效核验轮次不符合才隐藏；来源阻塞或关键数据缺失不推进轮次。隐藏不删除数据库和档案。

单次价格回撤不触发固定止损。连续两个有效定时确认轮次相对前一确认价收低，视为上升趋势破坏后仍未恢复，按第二个确认价模拟清仓并转入“过往监测”。停止后保留全部数据库样本、模拟账本、曲线和 Markdown 档案，供后续复盘；旧规则已经归档的项目不得自动复活。

首次发现满足基础条件的新候选时只保存待确认状态。下一独立扫描仍合格且价格不高于首次候选价时记录洗盘回踩；第三个独立扫描仍合格、价格高于回踩价且不超过首次候选价110%时，才登记 baseline 并发送正式命中。不得用同轮重复查询冒充下一轮确认。


## 当前费用规则（取代此前统一6%假设）

按每个标的所在链采用当前官方平台手续费规则（2026-09-06核查：https://help.fomo.family/en/articles/14436214-trading-fees-on-fomo）：BSC/BNB、Robinhood、Base、Monad、Ethereum每笔0.5%，网络费另计；Solana单笔<5U固定0.10U、5–47.5U为2%、47.5–190U固定0.95U、≥190U为0.5%，Solana网络费由平台承担。每次分批卖出按实际模拟卖出金额重新计费，回本按平台费后净收金额反解。未核验的网络费、代币买卖税、池费、滑点及价格冲击不能宣称已计入，也不能标为实测0。未验证邀请码或特殊代币优惠时不应用优惠。展示为平台费后估算收益，非全部费用后的真实盈亏。
采样时逐个检查该关注对象可见的费用信息；将官方规则、网络费/买卖税是否可核验及来源URL写入sample.note，未知明确写未知，严禁使用买入/卖出按钮执行交易来核验。页面默认由引擎按链和逐笔金额计算平台费；其他费用没有可靠证据时单列未计入。

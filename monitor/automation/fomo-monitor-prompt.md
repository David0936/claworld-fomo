# Fomo 自动化监测提示词

每次运行先阅读项目内 `INTEGRATION.md` 和 `PORTFOLIO.md`，严格执行其中的数据验证、扫描状态、样本登记和消息入队规则。

扫描 GMGN 支持的 Robinhood、BSC、Solana、Base、Ethereum 热搜。候选必须创建 1–7 天、当前市值 20万–50万美元，并通过 Windvane 按完整 CA 核验。Fomo 持仓占比下界至少 15% 才命中；15%–20% 为观察信号，20% 以上为强信号。不得用 Top10、DS 或其他百分比替代 Fomo 占比。

发现新命中后，立即用 `bridge.py baseline` 登记首次合格观测，用 `bridge.py event` 入队消息，不等待整轮结束。对已有标的刷新真实价格，并按两小时间隔做生命周期确认。达到 2、3、5、10 倍、从采样高点回撤 25%、相对首次合格价下跌达到40%，或模拟策略触发时入队提醒。跌幅达到40%立即记录终值并停止重点跟踪，转入过往监测，不等待3轮；历史样本与档案全部保留。没有新事件且状态未变化时保持静默。

每一轮还要依据 `PORTFOLIO.md` 为主清单内每个标的记录一次 `watch_round`、`watch_eligible` 和 `eligibility_reason`。不再符合年龄、市值或 Fomo 下界规则的标的先标记可能移出；连续3个不同筛选轮次仍不符合后才从主清单隐藏，期间重新符合立即清零。只有本轮三项资格数据完整可核验时才写这些字段；登录、配额、来源故障或关键数据缺失不算失败轮次。不得删除历史样本或档案。

100U 模拟使用项目内逐链官方平台费规则；每次分批卖出独立计费。网络费、代币税、池费、滑点或价格冲击没有可靠证据时必须标为未核验，不能当成零。严禁自动买卖、充值、授权、连接钱包或执行任何资金操作。

用户已授权把合格信号、生命周期和策略提醒发送到本机工作台已启用的飞书及 Telegram 接收方。密钥只由本机服务读取，自动化不得输出或复制凭证。

# 更新日志

## 0.5.1 - 2026-09-06

- 仓库随项目分发自动监测 Skill，并提供多 Agent 安装方式。

## 0.5.0 - 2026-09-06

- 新候选采用“首次候选→洗盘回踩→重新上涨”的三轮确认后再建立100U模拟买点。
- 使用连续两个确认轮次收低作为趋势退出，不再使用固定百分比止损。
- 模型2扩展为2倍回本，以及4×/8×/16×/后续翻倍持续减半滚仓。
- 新增持久化归档表，保留已经退出的历史状态。

## 0.4.1 - 2026-09-06

- 将模拟强制止损线调整为入场价的80%，触线即全仓止损并归档。
- 增加入场样本最高点警示，并为新候选加入跨轮防追高确认规则。

## 0.4.0 - 2026-09-06

- 过往监测曲线增加可交互交易节点，使用最高平台费后净值模型展示买入、分批卖出、清仓和退出监测事件。
- 点击节点显示该笔交易费用、到手金额和触发原因；重合事件自动错开。

## 0.3.1 - 2026-09-06

- 增加 Fomo 占比跌破15%的即时全仓退出规则、红色行状态和手续费后模拟结果。

## 0.3.0 - 2026-09-06

- 增加40%跌幅即时归档规则，与资格变化的连续3轮规则分开处理。
- 增加过往监测页面及价格曲线，历史数据只归档、不删除。

## 0.2.1 - 2026-09-06

- 修复直接通过 `file://` 打开静态首页时的无样式渲染，自动转到运行中的本机服务。

本项目遵循语义化版本。版本号同时保存在 `VERSION`，本机工作台据此检查 GitHub 更新。

## 0.2.0 — 2026-09-06

- 高亮最新进入主清单的标的，标注为当前规则观察点。
- 新增“可能移出”状态；连续3个独立筛选轮次不符合后从主清单隐藏，历史档案继续保留。

## 0.1.1 — 2026-09-06
